# 霸服 · 原生微信小程序开发版

使用 WXML、WXSS、JavaScript；不嵌入网页。七类内容和所有插画随包提供，抽取、图鉴和记录在本地运行。无需服务器、云开发或 LLM。

## 在微信开发者工具中打开

1. 从微信官方站点安装开发者工具：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 选择“导入项目”，目录选择本 README 所在的 `miniprogram` 文件夹。
3. 有已注册的小程序时填写它的 AppID；尚未注册可选择“测试号/无 AppID”，先检查基础页面。仓库中的 `touristappid` 是占位值，不是可发布 AppID。
4. 使用稳定版基础库，建议 3.6.0 或更新；点击“编译”。没有 npm 运行依赖，无须构建 npm。
5. 要真机预览、微信分享和上传，切换到真实 AppID，并确保当前微信账号有对应开发权限。

真实 AppID 在导入时填写，工具可能同步修改 `project.config.json`；AppID 是项目标识，不是上传凭证。本地编辑器设置文件 `project.private.config.json` 已加入 Git 忽略。不得把上传私钥、账号凭证或企业邮箱放进仓库。

## 功能

- 首页：七份 Buff、进度、单项重抽、一键融合仪式。
- 单项动画：摇签、洗牌、星图、符文、翻书、六次掷钱、幸运签条。
- 一键抽取：完整融合动画结束后，七个结果一次性提交和展示；关闭动画、退出页面和跨日未完成的抽取不保存。
- 结果：详情放在原来的结果栏位里；全套完成有满格反馈。出门卡通过本地 Canvas 生成 PNG，打开预览后长按保存。
- 图鉴：100 签、22 塔罗、12 星座、24 卢恩、16 神话、64 卦、16 幸运签条；关键词搜索、签等筛选、塔罗正逆位切换。
- 记录：按天保存；可复制 JSON 备份或粘贴导入，兼容网页备份。已有本地结果在同日冲突时优先保留。
- 分享：原生微信分享邀请朋友打开产品。个人抽取记录不会通过分享链接传给别人；分享具体结果可复制文案或保存出门卡。

塔罗正逆位各 50%。六类内容池重抽避开紧邻的上一项，三钱六爻仍保留 1:3:3:1 的传统概率，所以卦象可能重复。使用 `Math.random` 作娱乐抽取，不用于安全、付费抽奖或权益分配。

## 代码结构与内容同步

```text
app.*                 小程序入口和共享样式
pages/home            首页和抽取事务
pages/result          今日结果、图鉴详情和出门卡
pages/catalogue       图鉴和搜索筛选
pages/history         本地记录和备份
components/ritual     可取消的动画组件
components/reading    统一的结果详情组件
core/fortune.js       抽取、起卦、校验、备份合并和内容视图
adapters/store.js     微信本地存储
adapters/card.js      微信 Canvas 图片导出
data/content.js       自动生成的内容模块
assets/generated      自动生成的独立 SVG 图片
```

网页内容文件是同一套数据和插画的源头。从仓库根目录运行：

```bash
node scripts/build-miniprogram-data.mjs
node scripts/test-miniprogram.mjs
node scripts/validate.mjs
```

内容生成不需要网络或第三方依赖。不要直接编辑 `data/content.js` 或 `assets/generated`；先编辑网页对应数据文件，再重新生成。GitHub Actions 检查生成内容与源文件一致；网页发布包仅取根目录网页资源。

## 验证状态

已进行内容完整性、64 卦映射、抽取概率、重抽、正逆位、动画取消、原子保存、存储失败、网页备份导入、搜索、页面控制器和 Canvas 导出流程的自动验证。

这些验证使用 Node.js 与模拟的微信 API，不能代替微信开发者工具编译和真机测试。本次开发环境未安装微信开发者工具，也没有真实小程序 AppID，因此尚未确认原生编译、iOS/Android 动画和 SVG 字体、真实微信分享、长按保存行为。开发者工具中的基础库版本与真机基础库可能不同。

真机检查顺序：

1. 冷启动，单独抽取全部七种 Buff；动画前无结果、动画后保存。
2. 抽取中关闭或切到后台：不保存未完成的结果；一键仪式不逐项泄露结果。
3. 重抽、返回首页、杀进程再打开：最近结果正确且同日可重复查看。
4. 塔罗正逆位、六爻动爻、本卦与之卦，六十四卦图鉴全都有图。
5. 图鉴搜索、签等筛选、详情返回列表，浏览图鉴不修改记录。
6. 长篇结果生成 PNG、长按保存、真实微信分享；在 iOS 和 Android 各检查一次。
7. 导入网页旧备份、导入同日冲突记录、错误备份、次日重新打开。
